Без кошелька, только `bitcoinrb` в `irb` и mempool.space Signet:

1. Из приватного ключа получить три адреса: P2PKH, P2WPKH, P2TR. Для каждого записать префикс и длину.
2. Взять любую подтверждённую транзакцию в Signet-эксплорере с ≥2 входами и ≥2 выходами; по её hex (`GET /tx/{txid}/hex`) распарсить `Bitcoin::Tx.parse_from_payload` и вывести: txid, wtxid, vsize, weight, сумму входов (достать через `/tx/{prev}/`), сумму выходов, комиссию, sat/vB. Сверить с эксплорером.
3. Для каждого выхода определить тип скрипта по `script_pubkey` (без эксплорера) и восстановить адрес.
4. Собрать свою транзакцию с одним P2WPKH-входом и двумя выходами, подписать, **не отправлять**; посчитать её vsize до подписи (оценка) и после (факт) — разница не больше 2 vB.
5. Построить 2-of-3 P2WSH-адрес из трёх своих ключей и выписать witness script в человекочитаемом виде (`to_s`).

Критерий: все числа из п. 2 совпадают с эксплорером; на листе — схема «входы → выходы → комиссия» для разобранной транзакции.
