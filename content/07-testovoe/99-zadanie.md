---
title: "Задание: код-ревью собственного решения глазами проверяющего"
hot: false
sub: "практика · 20–40 мин"
---
1. Клонировать свой репозиторий в чистую директорию и выполнить README с нуля (включая Docker) с секундомером; записать все места, где пришлось думать или гуглить.
2. Пройти список edge-case из раздела и для каждого поставить статус: воспроизведено/обработано/не обработано. Два «не обработано» исправить.
3. Запустить `rubocop` с дефолтным конфигом и `bundle audit`; все замечания либо исправить, либо явно отключить с комментарием почему.
4. Удалить из кода все комментарии вида «что делает строка»; оставить только «почему так».
5. Сделать коммит-историю читаемой: `git rebase -i`, не более 10 коммитов с осмысленными сообщениями на английском.
6. Записать на телефон 2-минутный рассказ о решении на английском по структуре из раздела «Английский» и отправить ссылку на видео себе — пересмотреть на следующий день.

Критерий: установка по README занимает < 5 минут у человека, который видит проект впервые; `git log --oneline` читается как changelog.
